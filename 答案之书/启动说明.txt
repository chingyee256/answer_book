📖 答案之书 - 启动指南
=========================

🎯 最简单的方法：
双击打开 index.html 文件即可在浏览器中运行！

📱 使用方法：
1. 心中默念你的问题
2. 点击「打开答案」按钮
3. 欣赏书页翻动的动画和音效
4. 获取神秘的答案
5. 点击「再问一次」返回书的封面，开始新的问询

✨ 主要功能：
- 📖 随机答案：每次点击获得不同的启发
- 💖 收藏功能：保存喜欢的答案
- 🌟 精美动画：增强的3D书页翻动效果
- ✨ 光影特效：动态光晕流动 + 粒子飘散
- 🎵 背景音乐：柔和钢琴旋律（可开关）
- 🔊 翻页音效：真实的纸张翻动声
- ⌨️  键盘快捷键：
  • 空格键 / 回车：在欢迎页打开答案 / 在答案页返回封面
  • F 键：收藏答案
  • ESC 键：随时返回首页

🎵 音乐控制：
- 点击右下角的 🎵 按钮开启/关闭背景音乐
- 音乐状态会自动保存
- 页面切换到后台时自动暂停

🎨 动画效果：
- 书本打开动画：点击按钮时触发
- 3D翻页效果：带透视和亮度变化
- 光晕流动：四向移动的渐变光效
- 粒子效果：答案出现时的魔法粒子
- 文字淡入：从模糊到清晰的渐变

🚀 可选：使用本地服务器（推荐）

方法1 - 使用 Python：
  python -m http.server 8000
  然后访问：http://localhost:8000

方法2 - 使用 Node.js：
  npx http-server -p 8000
  然后访问：http://localhost:8000

💡 提示：
- 所有数据保存在本地浏览器中
- 清除浏览器缓存会删除收藏和音乐设置
- 可在 script.js 中添加自定义答案
- 音乐和音效使用 Web Audio API 合成，无需额外文件
- 推荐使用 Chrome 或 Edge 浏览器获得最佳效果
