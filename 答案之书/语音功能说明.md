# 🔊 语音朗读功能说明

## ✨ 新增功能

### 1. 自动语音朗读
答案出现后，系统会自动朗读答案内容（延迟1.5秒，等待动画完成）。

### 2. 手动朗读按钮
- 位置：答案页面，"再问一次"和"收藏"按钮之间
- 图标：🔊 朗读答案
- 功能：点击可以重新朗读当前答案

### 3. 键盘快捷键
- 按 `S` 键：在答案页面朗读答案

---

## 🎯 使用方法

### 自动朗读
1. 打开答案之书
2. 心中默念问题
3. 点击"打开答案"
4. 等待翻书动画完成
5. **系统自动朗读答案**

### 手动朗读
**方法1 - 点击按钮**
- 在答案页面，点击 **🔊 朗读答案** 按钮

**方法2 - 键盘快捷键**
- 在答案页面，按 `S` 键

---

## 🎨 语音特性

### 语音参数
- **语言**：中文（zh-CN）
- **语速**：0.9（略慢于正常，更易理解）
- **音调**：1.1（略高于正常，更悦耳）
- **音量**：1.0（最大音量）

### 智能选择
- 自动选择系统中最好的中文语音
- 支持多种中文语音引擎
- 优先使用中文女声（如果有）

### 状态反馈
**朗读开始时：**
- 按钮变为绿色渐变
- 文字显示"🔊 朗读中..."
- Toast提示"🔊 开始朗读答案"

**朗读结束时：**
- 按钮恢复紫色渐变
- 文字恢复"🔊 朗读答案"

## ⚙️ 技术实现

### Web Speech API
使用浏览器原生的 `SpeechSynthesis` API：

```javascript
// 创建语音实例
const utterance = new SpeechSynthesisUtterance(text);

// 设置参数
utterance.lang = 'zh-CN';
utterance.rate = 0.9;
utterance.pitch = 1.1;
utterance.volume = 1.0;

// 开始朗读
speechSynthesis.speak(utterance);
```

### 智能控制
- 页面切换时自动停止朗读
- 新答案出现时取消旧朗读
- 错误处理和提示反馈

## 🔊 音量控制

### 系统音量
- 朗读音量受系统音量控制
- 可通过系统调节音量大小

### 独立控制
- 语音朗读与背景音乐独立
- 可以只开语音，关闭音乐
- 也可以两者同时开启
