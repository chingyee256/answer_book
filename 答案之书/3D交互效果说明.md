# 🎮 3D鼠标跟踪交互效果说明

## ✨ 功能概述

书本封面现在会跟随鼠标移动产生3D倾斜效果，让界面更加生动有趣！

---

## 🎯 效果特点

### 1. **3D旋转跟踪**
- 鼠标在书本上移动时，书本会产生3D倾斜
- 水平移动 → 书本左右旋转（Y轴）
- 垂直移动 → 书本上下旋转（X轴）
- 旋转角度限制在 ±20度，看起来自然舒适

### 2. **动态阴影**
- 阴影会随着鼠标位置动态变化
- 增强3D立体感
- 让书本看起来真的"悬浮"在空中

### 3. **平滑过渡**
- 使用 0.1 秒的过渡动画
- 移动流畅不生硬
- 视觉体验极佳

### 4. **智能暂停**
- 鼠标悬停时，原有的悬浮动画会暂停
- 避免动画冲突
- 让3D跟踪效果更明显

### 5. **恢复原位**
- 鼠标离开书本区域后，自动恢复初始状态
- 平滑回到原位

## 🎨 技术实现

### CSS 关键属性
```css
.book-cover {
    transform-style: preserve-3d;  /* 保持3D变换 */
    transition: transform 0.1s ease-out, box-shadow 0.1s ease-out;  /* 平滑过渡 */
}

.book-container:hover .book {
    animation-play-state: paused;  /* 暂停悬浮动画 */
}
```

### JavaScript 核心逻辑
```javascript
// 计算鼠标相对位置（-0.5 到 0.5）
const x = (e.clientX - rect.left) / rect.width - 0.5;
const y = (e.clientY - rect.top) / rect.height - 0.5;

// 转换为旋转角度
const rotateY = x * 20;  // 水平旋转
const rotateX = -y * 20; // 垂直旋转

// 应用3D变换
bookCover.style.transform = `
    perspective(1000px)
    rotateX(${rotateX}deg)
    rotateY(${rotateY}deg)
    scale(1.02)
`;
```

## 🔧 自定义调整

### 调整旋转幅度
在 `script.js` 中修改旋转系数：
```javascript
const rotateY = x * 20; // 改为 x * 30 可以增大旋转幅度
const rotateX = -y * 20; // 改为 -y * 30 可以增大旋转幅度
```

### 调整过渡速度
在 `style.css` 中修改过渡时间：
```css
transition: transform 0.1s ease-out; /* 改为 0.2s 会更缓慢 */
```

### 调整缩放比例
在 `script.js` 中修改 scale 值：
```javascript
scale(1.02)  // 改为 1.05 会有更明显的放大效果
```

### 禁用此效果
如果不想要此效果，可以删除或注释掉 `script.js` 中的相关代码：
```javascript
// 注释掉这些行即可禁用
// bookContainer.addEventListener('mousemove', handleMouseMove);
// bookContainer.addEventListener('mouseleave', handleMouseLeave);
```
