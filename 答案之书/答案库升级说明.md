## 🔄 防重复机制

### 工作原理

1. **历史记录跟踪**
   - 系统会记录最近出现的 20 个答案
   - 新答案不会从这 20 个中选择
   - 确保至少 20 次不重复

2. **智能清理**
   - 当可选答案少于总数的 30% 时
   - 自动清空一半的历史记录
   - 保证始终有足够的新鲜答案

3. **优雅降级**
   - 如果答案库太小（≤20条）
   - 自动禁用防重复功能
   - 保证程序稳定运行

### 算法优势

✅ **高效过滤** - 快速排除最近的答案
✅ **自动平衡** - 动态调整历史记录
✅ **用户友好** - 几乎感觉不到重复
✅ **性能优良** - 计算开销极小

## 🛠️ 技术实现

### 核心代码

```javascript
// 最近出现过的答案（防重复）
let recentAnswers = [];
const MAX_RECENT_ANSWERS = 20;

function getRandomAnswer() {
    // 获取可用的答案（排除最近出现过的）
    let availableAnswers = answers.filter(answer => 
        !recentAnswers.includes(answer)
    );
    
    // 智能清理历史记录
    if (availableAnswers.length < answers.length * 0.3) {
        const keepCount = Math.floor(MAX_RECENT_ANSWERS / 2);
        recentAnswers = recentAnswers.slice(-keepCount);
        availableAnswers = answers.filter(answer => 
            !recentAnswers.includes(answer)
        );
    }
    
    // 随机选择并记录
    const randomIndex = Math.floor(Math.random() * availableAnswers.length);
    const selectedAnswer = availableAnswers[randomIndex];
    recentAnswers.push(selectedAnswer);
    
    // 维护历史记录大小
    if (recentAnswers.length > MAX_RECENT_ANSWERS) {
        recentAnswers.shift();
    }
    
    return selectedAnswer;
}
```

### 算法复杂度
- **时间复杂度**: O(n) - n 为答案总数
- **空间复杂度**: O(k) - k 为历史记录数量（固定20）
- **性能影响**: 几乎可以忽略不计
