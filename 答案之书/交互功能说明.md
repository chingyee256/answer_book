# 🎨 交互功能详细说明

## 增强的动画效果

### 1️⃣ 书页翻动动画

当你点击"打开答案"时，会触发以下精美动画：

**注意**：点击"再问一次"会返回书的封面，而不是直接显示新答案。这样的设计让每次获取答案都更有仪式感。

#### 📖 书本打开动画
- **触发时机**：点击打开答案按钮时
- **效果**：书本封面进行3D旋转，模拟书本打开的动作
- **持续时间**：1秒
- **技术实现**：CSS 3D transform with perspective

```css
/* 书本打开效果 */
@keyframes bookOpen {
    0% { transform: perspective(1000px) rotateY(0deg); }
    50% { transform: perspective(1000px) rotateY(-80deg); }
    100% { transform: perspective(1000px) rotateY(0deg); }
}
```

#### 📄 增强的翻页效果
- **触发时机**：答案页面显示时
- **效果特点**：
  - 3D透视旋转（从90度到0度）
  - 缩放变化（从0.8到1）
  - 透明度渐变（从0到1）
  - 亮度变化（从暗到亮）
- **持续时间**：1秒
- **分段动画**：
  - 0-25%：初始翻开，较暗
  - 25-50%：继续翻开，逐渐变亮
  - 50-75%：接近完成，略微过冲
  - 75-100%：完全展开

#### ✨ 答案文字淡入
- **触发时机**：翻页动画进行到一半时
- **效果**：文字从模糊到清晰，从下方浮现
- **延迟**：0.5秒（等待翻页动画进行到一半）
- **持续时间**：0.8秒

### 2️⃣ 光影效果

#### 💫 动态光晕流动
答案卡片上的光效会持续移动和变化：

- **移动模式**：四向移动（对角线 + 上下左右）
- **透明度变化**：0.3 ↔ 0.7 循环
- **缩放变化**：1.0 ↔ 1.15 循环
- **循环周期**：4秒
- **颜色**：
  - 中心：白色光晕（20%透明度）
  - 次要：淡黄色（15%透明度）
  - 边缘：白色透明渐变

#### ✨ 增强星光闪烁
书本封面上的装饰星星：

- **闪烁周期**：2秒
- **效果组合**：
  - 透明度：0.5 ↔ 1
  - 缩放：1.0 ↔ 1.2
  - 旋转：-10° ↔ 0° ↔ 10°
  - 发光强度：5px ↔ 20px

#### 🌟 粒子飘散效果
答案出现时的魔法粒子：

- **粒子数量**：20个
- **出现位置**：答案卡片中心区域随机分布
- **运动轨迹**：向上飘散并逐渐消失
- **生命周期**：3秒
- **特性**：
  - 随机位置
  - 随机动画延迟（0-0.5秒）
  - 向上移动100px
  - 逐渐缩小并消失
- **创建时机**：每次显示新答案时

## 🎵 背景音乐功能

### 音乐控制

#### 🎵 控制按钮
- **位置**：右下角固定浮动按钮
- **尺寸**：60x60px（桌面）/ 50x50px（移动端）
- **状态指示**：
  - 🎵 播放中（带旋转动画和脉冲光效）
  - 🔇 已静音（灰色，无动画）

#### 🎹 音乐特点
使用 **Web Audio API** 实时合成音乐：

**音符序列**：
```
C5 (523.25 Hz) - 0.5秒
D5 (587.33 Hz) - 0.5秒
E5 (659.25 Hz) - 0.5秒
F5 (698.46 Hz) - 0.5秒
G5 (783.99 Hz) - 1秒
E5 (659.25 Hz) - 0.5秒
D5 (587.33 Hz) - 1秒
```

**特性**：
- 波形：正弦波（sine）
- 音量：10%（柔和不打扰）
- 淡入淡出：每个音符有0.1秒淡入
- 循环播放：自动重复

**优点**：
- ✅ 无需下载音频文件
- ✅ 体积极小，加载快速
- ✅ 跨平台兼容性好
- ✅ 可自定义音符和节奏

#### 💾 记忆功能
- 音乐开关状态保存在 LocalStorage
- 下次访问自动恢复上次设置
- 键名：`musicEnabled`

#### 🔄 智能控制
- **页面后台**：自动暂停音乐
- **页面前台**：恢复播放（如果之前是开启状态）
- **点击切换**：即时反馈，显示提示消息

### 🔊 翻页音效

#### 音效特点
- **触发时机**：每次打开答案或再问一次
- **声音特性**：
  - 起始频率：400 Hz
  - 结束频率：100 Hz
  - 持续时间：0.2秒
  - 音量：30%
  - 频率变化：指数衰减（模拟纸张摩擦）

#### 实现方式
```javascript
oscillator.frequency.setValueAtTime(400, currentTime);
oscillator.frequency.exponentialRampToValueAtTime(100, currentTime + 0.2);
gainNode.gain.setValueAtTime(0.3, currentTime);
gainNode.gain.exponentialRampToValueAtTime(0.01, currentTime + 0.2);
```

#### 声音模拟
- 高频到低频的滑动
- 音量逐渐减弱
- 模拟真实的纸张翻动声

## 💡 使用建议

1. **首次使用**：建议开启背景音乐，获得最佳沉浸体验
2. **安静环境**：可以关闭音乐，仅保留视觉效果
3. **移动端**：建议竖屏使用，横屏也完全支持
4. **浏览器**：推荐使用 Chrome 或 Edge 获得最佳效果
5. **音量控制**：如觉得声音过大/小，可通过浏览器或系统音量调节
