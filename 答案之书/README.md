# 📖 答案之书

一个神秘又启发性的网页应用，帮助你在犹豫、纠结或好奇时获得灵感。

## ✨ 功能特点

- 🎲 **随机答案**：每次点击都会获得一句独特的启发性语句
- 💖 **收藏功能**：保存你喜欢的答案到本地
- 🌟 **精美动画**：流畅的页面切换和增强的书页翻开效果
- 🎵 **背景音乐**：柔和的钢琴旋律，可自由开关（使用Web Audio API合成）
- 🔊 **翻页音效**：打开答案时的逼真翻页音效
- ✨ **光影效果**：动态光晕流动和粒子飘散特效
- 🌌 **星空背景**：沉浸式的动态星空视觉体验
- 📱 **响应式设计**：完美支持手机和电脑浏览
- ⌨️ **键盘快捷键**：支持快捷键操作

## 🚀 使用方法

### 本地运行

1. 下载所有文件到本地目录
2. 双击打开 `index.html` 文件
3. 或者使用本地服务器运行（推荐）：

```bash
# 如果安装了 Python 3
python -m http.server 8000

# 如果安装了 Node.js 和 http-server
npx http-server -p 8000
```

4. 在浏览器中访问 `http://localhost:8000`

## 📖 使用说明

### 主页面
1. 心中默念你的问题
2. 点击「📖 打开答案」按钮
3. 系统会随机展示一句启发性的答案

### 答案页面
- **🔁 再问一次**：返回书的封面，重新开始寻找答案的旅程
- **💖 收藏**：将当前答案保存到收藏列表

### 背景音乐控制
- 点击右下角的 **🎵 音乐按钮** 开启/关闭背景音乐
- 音乐状态会自动保存，下次访问时自动恢复
- 页面切换到后台时自动暂停，返回时恢复播放

### 收藏页面
- 点击主页的「💖 我的收藏」查看所有收藏
- 每条收藏显示答案内容和收藏时间
- 可以删除不需要的收藏

## ⌨️ 键盘快捷键

- `空格键` 或 `回车键`：在欢迎页打开答案 / 在答案页返回封面
- `F 键`：收藏当前答案
- `ESC 键`：随时返回首页

## 🔧 自定义

### 添加更多答案

编辑 `script.js` 文件中的 `answers` 数组：

```javascript
const answers = [
    "你的自定义答案1",
    "你的自定义答案2",
    // ... 更多答案
];
```

### 修改样式

编辑 `style.css` 文件来自定义：
- 颜色主题
- 字体大小
- 动画速度
- 布局样式
