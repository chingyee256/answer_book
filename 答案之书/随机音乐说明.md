# 🎵 随机音乐功能说明

## ✨ 功能概述

每次打开网页时，系统会从音乐库中随机选择一首久石让风格的钢琴曲播放，让每次体验都充满新鲜感！

## 🎲 随机机制

### 随机时机
- ✅ **页面刚打开时** - 自动随机选择一首
- ✅ **刷新页面** - 重新随机选择
- ✅ **重新打开链接** - 每次都是新的随机结果

### 随机范围
- 从 5 首久石让风格钢琴曲中随机选择
- 每首曲子被选中的概率均等（20%）
- 完全随机，可能连续出现相同曲目

### 查看当前曲目
打开浏览器的**开发者工具**（F12），在控制台中可以看到：
```
🎵 正在播放: 天空之城
```
显示当前正在播放的是哪首曲子。

## 🎼 音乐特点

### 久石让风格特征
每首曲子都精心设计，融入了久石让音乐的特色：

1. **简洁优美的旋律**
   - 不复杂繁琐
   - 每个音符都有意义
   - 易于记忆和传唱

2. **温柔的钢琴音色**
   - 使用低通滤波器
   - 温暖柔和的音质
   - 舒缓的音量渐变

3. **和弦伴奏支持**
   - 每首曲子都有精心设计的和弦进行
   - 为主旋律提供和声支持
   - 增加音乐的层次感和深度

4. **适当的留白**
   - 休止符的使用
   - 循环间的停顿
   - 让音乐有呼吸感

## 🎚️ 音乐控制

### 播放控制
- 🎵 **自动播放** - 页面加载后自动开始（某些浏览器需要用户交互后才能播放）
- ⏯️ **暂停/继续** - 点击右上角音乐按钮
- 🔇 **静音** - 再次点击音乐按钮
- 🔄 **循环播放** - 音乐会自动循环，无需手动操作

### 按钮状态
- 🎵 **绿色跳动** - 音乐正在播放
- 🔇 **灰色静止** - 音乐已暂停/静音

## 🔧 技术实现

### 核心代码
```javascript
// 音乐库定义
const musicLibrary = [
    {
        name: "天空之城",
        melody: [...],  // 主旋律音符
        chords: [...]   // 和弦进行
    },
    // ... 其他曲目
];

// 随机选择
let selectedMusic = musicLibrary[Math.floor(Math.random() * musicLibrary.length)];
console.log('🎵 正在播放:', selectedMusic.name);
```

### 音乐合成
- 使用 **Web Audio API** 实时合成音乐
- 不需要下载音频文件
- 体积小，加载快
- 跨平台兼容性好

## 🎨 自定义扩展

### 添加新曲目
想要添加更多曲目？在 `script.js` 中的 `musicLibrary` 数组中添加新对象：

```javascript
{
    name: "你的曲目名称",
    melody: [
        { type: 'note', freq: 523.25, dur: 1.0 },  // C5
        { type: 'note', freq: 659.25, dur: 1.0 },  // E5
        // ... 更多音符
    ],
    chords: [
        { time: 0, freqs: [261.63, 329.63, 392.00], dur: 4.0 },
        // ... 更多和弦
    ]
}
```

### 调整随机概率
如果想让某些曲目更容易被选中，可以在数组中重复添加：

```javascript
const musicLibrary = [
    music1,
    music2,
    music3,
    music1,  // music1 被选中的概率是其他的 2 倍
];
```

### 固定播放某首曲子
如果你只喜欢某一首，可以注释掉随机逻辑：

```javascript
// let selectedMusic = musicLibrary[Math.floor(Math.random() * musicLibrary.length)];
let selectedMusic = musicLibrary[0];  // 固定播放第一首
```

## 🌟 体验建议

### 最佳体验
1. 打开网页后，聆听一会儿当前的曲目
2. 如果想听其他曲子，刷新页面即可
3. 每次寻找答案前，先感受一下音乐的氛围
4. 让音乐引导你的心境

### 注意事项
- 某些浏览器需要用户交互（如点击）后才能自动播放音乐
- 首次播放可能有短暂延迟（浏览器初始化 Audio Context）
- 音乐合成可能会占用少量 CPU 资源（非常轻微）
- 不同设备/浏览器的音色可能略有差异
